# Motion events need the python websockets package. This file pins exactly
# which bytes may be installed, because the review that approves this plugin
# has to bind to something that cannot change afterwards: an unpinned
# `pip install websockets` resolves against a registry that is free to serve
# different code tomorrow, and that code runs on this machine.
#
# Reported at the security review of the marketplace submission:
# https://github.com/omacom/omarchy-plugin-marketplace/issues/3558#issuecomment-5544021186
#
# The wheels are the Linux ones this widget can actually run on, plus the
# source archive as a fallback. `pip --require-hashes` refuses anything whose
# digest is not in here, and refuses the whole install if any requirement is
# unpinned, so this file is the boundary rather than a suggestion.
#
# To move to a new version: bump it here with its hashes, in one commit, and
# ask for a re-check. Do not widen the pin.
